# Security policy

Only the current beta receives fixes. Apple Developer ID signing/notarization, independent security review and clean-Mac internet-download acceptance have not been completed.

Report vulnerabilities using [GitHub private vulnerability reporting](https://github.com/maxuod/answerpouch/security/advisories/new). Never include credentials, cookies, account identities or raw customer exports. If unavailable, open a minimal issue asking for a private route without exploit details.

Preserve dedicated profile isolation, positive current-account proof, frozen-question integrity, explicit submission consent, minimal Chromium environment, renderer isolation/CSP, saved-URL-only opening, pinned official downloads and no automatic replay/fallback. These controls do not establish platform approval or complete capture.

Do not disable Gatekeeper, strip quarantine attributes, bypass CAPTCHA/restrictions, rotate identities after a restriction or change OS trust. Unexpected damage/malware warnings are a stop. Device/account authentication stays with the user.

中文：通过 GitHub 私密漏洞报告反馈，不公开身份、Cookie、密钥或客户原始证据。当前为测试版，未完成正式签名、公证及独立安全认证，不要关闭系统保护或绕过访问限制。
