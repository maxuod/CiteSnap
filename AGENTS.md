# AnswerPouch

Working product name: AnswerPouch. Local extraction project; no public release has occurred.

Keep browser collection independent from getaudit, Electron, GSC, databases, brand scoring and reports. Runtime files go through the package files allowlist. Never copy real profiles, cookies, credentials, ledgers, raw customer answers or historical reports into this repository.

Every Chromium launch must explicitly use createBrowserEnvironment(): only own string HOME, PATH, TMPDIR, LANG values in a fresh null-prototype object. Preserve strict guest isolation, separate dedicated authenticated profiles, positive account verification and cancellation/close behavior. CAPTCHA, rate limits, region or login restrictions are stops. No paid/API/visible fallback or automatic replay. Stored login is not proof of current login.

Preserve captured bytes, answer text, source links, extractor identifiers and historical evidence. Name changes do not authorize rewriting legacy evidence/profile markers. Test with synthetic or localhost fixtures unless the user explicitly authorizes real collection. Do not package or restart the installed getaudit app as part of extraction.
