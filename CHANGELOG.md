# Changelog

## 0.2.4 beta 1 — CiteSnap

- Renamed the public repository, visible application, current package, CLI entry, new capture labels and download to CiteSnap. Published the reviewed English/Chinese description of free GEO/AEO queries for company, website and product mentions, collected answers/citations and competitor review.
- Preserved the AnswerPouch data/session path, bundle ID, internal browser origin and evidence kinds. Old frozen files, saved records and dedicated profiles remain compatible; historical evidence is not rewritten. New captures identify CiteSnap and old AnswerPouch evidence still verifies.
- Retained the existing browser preparation, account/access checks, local network defaults and no-replay behavior. No new real-provider collection was requested for this release.
- Developer ID/notarization, another clean Mac's installation and broader real-account platform validation remain uncompleted. The release is an explicitly unnotarized beta.

## 0.2.3 beta 1 — first public AnswerPouch beta

- Apple Silicon macOS 13+ download; ordinary users need no Node.js, terminal or developer key.
- Explicit one-time official browser preparation, pinned version/size/SHA-256, bounded/cancellable download and no automatic retry. No Chrome for Testing or restricted browser components redistributed in our DMG.
- Existing frozen-question, own-account, selected-source, risk-review, collection/export flow and bilingual playful orange/white UI retained.
- Added install/first-login guide, privacy/security/contribution documentation, upstream MIT license, third-party notices, issue templates, CI and checksums.
- Copilot parser remains unchanged from 0.2.2. Earlier limited real acceptance is separate from new delivery checks.
- Developer ID/notarization, clean-Mac installation and broader real-account acceptance remain future work. This is a pre-release, not a notarized stable release.

## 0.2.2 — local candidate

Fixed native Copilot References coverage, excluded authored Sources headings. Final reader matched an existing 2,745-character automatic answer and six URLs without resubmission. 223 source tests passed plus one opt-in skip. Not publicly distributed.

## 0.2.1 / 0.2.0 — local candidates

Added current Copilot reply recognition and standalone desktop freeze/import/account/collection/export workflow. Historical failed and successful observations remain immutable.

## 0.1.0 — extraction baseline

Separated seven browser modules from getaudit with compatibility exports and original hashes. Existing getaudit consumers remain pinned until separately upgraded.
