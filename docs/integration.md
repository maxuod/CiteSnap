# getaudit integration

The provisional AnswerPouch name and version 0.1.0 identify this local extraction. getaudit consumes a fixed package archive plus lockfile integrity; it does not depend on a sibling filesystem path or download unreviewed branch tips at runtime.

The original desktop module paths are compatibility exports. Future collection manifests include the actual package's seven original runtime sources and package metadata, in addition to caller scripts. Existing extractor identifiers and profile markers remain stable. Historical evidence is never rewritten when the collector is renamed or updated.

getaudit keeps database ownership, project/question plans, submission checkpoints, retry authorization, quality classification, brand/citation calculations, GSC and reports. AnswerPouch does not upload to the hosted workspace. A browser collector repository does not grant a website access to a local Chrome session.

Current validation: 203 standalone tests passed with one opt-in real-browser skip; 1,662 consumer tests passed with one skip. These are synthetic/local tests; no new real-provider sampling or desktop installation was performed. Initial extracted modules retain exact hashes recorded in source-provenance.json.
